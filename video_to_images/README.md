# โปรแกรมแยกวิดีโอเป็นภาพ

ดับเบิลคลิก `Start.bat` เพื่อเปิดโปรแกรมบน Windows เครื่องนี้

1. เลือกไฟล์วิดีโอและโฟลเดอร์บันทึกภาพ
2. ระบุช่วงเวลา เช่น `30` จะได้ภาพที่วินาที 0, 30, 60, 90… หรือ `0.5` สำหรับทุกครึ่งวินาที
3. เลือกความละเอียดต้นฉบับ ขนาดสำเร็จรูป หรือ “กำหนดเอง” แล้วใส่ความกว้างและความสูง
4. เลือก JPG หรือ PNG แล้วกด “เริ่มแยกภาพ”
5. เมื่อเสร็จ กด “เปิดโฟลเดอร์ผลลัพธ์”

เมื่อเปิดรักษาสัดส่วน ภาพจะมีขนาดใหญ่ที่สุดที่อยู่ภายในกรอบที่เลือกโดยไม่ยืดภาพและไม่เติมขอบ เช่น วิดีโอแนวตั้ง 1080×1920 ในกรอบ 1920×1080 จะได้ประมาณ 608×1080 ปิดตัวเลือกนี้หากต้องการขนาดตรงตามที่ระบุ (อาจทำให้ภาพยืด)

ทุกครั้งจะสร้างโฟลเดอร์ใหม่ ชื่อภาพมีลำดับและเวลาเป้าหมาย เช่น `frame_000002_00000030.000s.jpg` ภาพเริ่มต้นที่เวลา 0 เสมอ หากวิดีโอสั้นกว่าช่วงเวลาที่ตั้งไว้จะได้หนึ่งภาพ ปุ่มยกเลิกเก็บภาพที่บันทึกไว้แล้ว ช่วงเวลาสั้นและภาพความละเอียดสูงใช้พื้นที่มากขึ้น

รองรับ MP4, MOV, MKV, AVI และรูปแบบที่ตัวถอดรหัส OpenCV ในเครื่องอ่านได้ ความยาว จำนวนภาพ และตำแหน่งเวลาเป็นค่าประมาณตามข้อมูลของไฟล์และตัวถอดรหัส โดยเฉพาะวิดีโอที่มีอัตราเฟรมไม่คงที่ เวลาในชื่อไฟล์เป็นเวลาเป้าหมาย ไม่ใช่หลักฐานเวลาเฟรมแบบแม่นยำสำหรับงานนิติวิทยาศาสตร์ การขยายภาพไม่เพิ่มรายละเอียดจากต้นฉบับ

## ติดตั้งบนเครื่องอื่น

ใช้ Python 3.10 ขึ้นไป พร้อม tkinter แล้วเปิด Terminal ในโฟลเดอร์นี้:

```powershell
python -m pip install -r requirements.txt
python app.py
```

โปรแกรมทำงานในเครื่อง ไม่อัปโหลดวิดีโอ และไม่แก้ไขไฟล์ต้นฉบับ
